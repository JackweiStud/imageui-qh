# StyleMorph AI 项目深度分析报告 (PRD)

## 1. 项目概述
StyleMorph AI 是一个基于 React 18 和 Google Gemini AI 的高级图像处理 Web 应用，旨在提供从简单风格迁移到复杂换脸、姿态控制的多样化 AI 图像生成服务。

## 2. 核心功能模块

### 2.1 Style Mode (风格模式)
- **场景**: 单图 + 提示词风格化
- **功能**: 用户上传一张图片，选择预设风格（如“赛博朋克”、“商务装”）进行修改。
- **实现**: 
  - 模型: `gemini-2.5-flash-image`
  - 逻辑: 强调保持原始构图、人物身份和身体比例，仅修改风格表现。

### 2.2 Reference Mode (参考模式)
- **场景**: 换装/场景融合 (基于预设)
- **功能**: 用户上传照片 + 选择底部预设的参考场景/服装。AI 将用户特征融入参考场景。
- **实现**: 
  - 模型: `gemini-2.5-flash-image`
  - 逻辑: 双图输入（用户图 + 预设图）。Prompt 指示提取 Input 1 的面部/身份和 Input 2 的服装/背景进行合成，强调皮肤纹理真实感。

### 2.3 Free Mode (自由创作模式)
- **场景**: 文生图 / 图生图
- **功能**: 
  - **文生图**: 纯文本生成高质量图片。
  - **图生图**: 上传图片 + 自定义修改指令。
  - **配置**: 支持 4K 分辨率输出，自定义长宽比 (Aspect Ratio) 和清晰度。
- **实现**: 
  - 模型: `gemini-3-pro-image-preview`
  - 亮点: 使用更强的模型以支持高分辨率和精细指令遵循。

### 2.4 Custom Reference Mode (自定义参考模式)
- **场景**: 高级换脸 / 姿态控制 / 三图融合
- **功能**: 支持上传最多三张图片：
  1. **Source**: 面部特征源。
  2. **Target**: 背景和服装源。
  3. **Pose (可选)**: 骨架/姿态参考（支持上传手绘草图）。
- **实现**: 
  - 模型: `gemini-2.5-flash-image`
  - 逻辑: 复杂的执行顺序 Prompt（解析 Pose -> 应用 Target 服装 -> 移植 Source 面部）。

## 3. 关键技术亮点

### 3.1 智能图像压缩策略
为解决 LLM API Payload 限制及优化传输延迟，实现了前端智能压缩 (`services/geminiService.ts`):
- **单图模式**: 追求画质，Max 1024/2048px, Quality 0.8/0.9。
- **多图模式**: 追求成功率，Max 768px, Quality 0.6 (防止 Base64 过长)。
- **技术**: 使用 HTML5 Canvas + `toDataURL('image/jpeg')`。

### 3.2 内置 SketchPad (绘图板)
- **功能**: 全功能 Canvas 绘图工具（画笔、橡皮、颜色、线宽）。
- **应用**: 
  - **Input**: 绘制火柴人作为 Pose 参考。
  - **Post-Process**: 对生成结果进行涂改修复 (Inpainting 准备)，再回传给 AI 细化。

### 3.3 Prompt Engineering (提示词工程)
- **Role-Playing**: 设定 AI 角色 (如 "Expert Photo Editor", "Senior VFX Artist")。
- **Structured Prompting**: 使用 "Execution Order" (执行顺序) 和 "Visual Standards" (视觉标准) 结构化指令，提升稳定性。

## 5. 潜在改进方向
- **后端代理**: 引入后端服务隐藏 API Key，提高安全性。
- **状态管理**: 引入 Context 或 Redux 管理日益复杂的 App State。
- **错误处理**: 增强对网络波动和 API 限流的用户反馈。

## 6. 产品规划与功能增强 (Roadmap)

基于用户体验（消费者视角）与产品壁垒（PM 视角）的综合规划：

### P0: 基础体验完善 (Must have)
1. **Prompt 智能增强 (Magic Prompt)**:
   - 利用 Gemini 文本能力，将用户输入的简短描述（如“漂亮的女孩”）扩写为包含光影、材质、风格关键词的高质量 Prompt。
2. **滑块对比 (Slider View)**:
   - 在结果页增加原图/新图的左右拖动滑块，提供更直观的视觉冲击力，替代当前的弹窗对比。
3. **友好错误反馈**:
   - 优化错误处理机制，当图片因安全策略被拦截或生成失败时，提供具体且友好的提示，而非通用错误。

### P1: 核心功能增强 (Should have)
1. **本地历史记录 (Local History/Gallery)**:--功能已补齐
   - 实现侧边栏/抽屉式历史记录，保存最近 20-50 条生成记录。
   - 支持“参数回溯”，一键恢复某张历史图片的 Prompt 和配置。
2. **局部重绘 (Inpainting)**:
   - 升级 SketchPad，支持“遮罩模式”。用户涂抹特定区域（如多出的手指），AI 仅针对该区域进行重绘修复。
3. **一键社交分享**:
   - 增加生成“Before/After”拼接图并下载的功能，方便用户在社交媒体分享。

### P2: 商业化与扩展 (Nice to have)
1. **电商/垂直场景深化**:
   - **虚拟试衣 (Virtual Try-On)**: 优化 Prompt 逻辑，专门针对“换人不换衣”或“换衣不换人”场景。
   - **背景库集成**: 内置高质量背景（摄影棚、街景），减少用户搜寻素材成本。
2. **账户与云同步**:
   - 接入 Firebase/Supabase，实现多端历史记录同步。
3. **后端服务化 (BFF)**:
   - 搭建轻量级后端（如 Next.js API Routes）隐藏 API Key，实现速率限制和简单的用户鉴权。

*   **现状**: 目前的 `Reference Mode` 和 `Custom Swap` 功能很强大，接近商业级应用（如 AI 模特换装）。

#### 2. 架构与安全：后端服务化 (BFF Layer)
*   **严重隐患**: 目前 API Key 暴露在前端（或需要用户自己填）。这阻碍了产品的规模化推广。
*   **规划**:
    *   搭建轻量级后端（Next.js API Routes / Cloudflare Workers / Python FastAPI）。
    *   **功能**: 隐藏 API Key，实现速率限制 (Rate Limiting)，简单的用户鉴权。

#### 3. 用户体验细节 (UX Polish)

*   **对比体验**: 目前的 `ImageCompareModal` 是弹窗。更好的体验是在主界面直接支持 **“滑块对比 (Slider Comparison)”**，用户可以左右拖动滑块直观看到变化。

#### 4. 商业化探索 (Monetization)
*   即使是开源项目，也可以设计积分系统。
    *   **Token System**: 每次生成消耗积分。
